# 🚗 Online Garage Services

Online Garage Services is a full-service auto repair and maintenance platform built to provide convenient and reliable mobile auto repair solutions. Whether you're at home, work, or stuck on the road due to an emergency breakdown, our system connects you with trusted mechanics who come to your location at your preferred time and date.

<br>

**🔧 Features**

- Comprehensive vehicle maintenance and repair for all makes and models.

- On-demand mobile auto repair services at your chosen location and schedule.

- Emergency assistance if your vehicle stops unexpectedly in an unknown or remote area.

- Easy booking interface with scheduling and location tracking.

- Mechanic management and customer communication support.

<br>

**🛠️ Tech Stack**

- Frontend: HTML, CSS, JavaScript

- Backend: Python, Django

- Database: PostgreSQL

<br>

**🚀 Getting Started**

Follow the instructions below to set up the project on your local machine.

1. Clone the Repository: 
- git clone https://github.com/your-username/online-garage-services.git
- cd online-garage-services

<br>

2. Create a Python Virtual Environment
Make sure you have Python 3.8 or higher installed.
- python -m venv env

<br>

3. Activate the environment:

- On Windows: .\env\Scripts\activate
- On macOS/Linux: source env/bin/activate

<br>

4. Install Dependencies:
- pip install -r requirements.txt

<br>

5. Set Up the Database
- Ensure you have PostgreSQL installed and a database created. Update your settings.py with the correct database credentials.

<br>

6. Then run:
- python manage.py makemigrations
- python manage.py migrate

<br>

7. Run the Development Server:
- python manage.py runserver

<br>

8. Now visit http://127.0.0.1:8000/ in your browser to use the application.
